# Fase 10.5 — AgentArmor Security Gate (bloqueante)

Gate bloqueante: sin gate PASSED no se puede llegar a fase 11 (Deploy).
Inspirado en AgentArmor + OWASP Agentic AI Top-10.

## Sub-pasos en orden

- **[10.5a]** Si `.apex/security/` no existe, scaffolding automatico:
  `apex_security_gate(scaffold=true)`. Esto copia 8 plantillas L1-L8 +
  README.
- **[10.5b]** Completar cada `L*-*.md` con evidencia REAL del codigo del
  proyecto:
  - L1 Ingestion — validacion de inputs externos, sanitizacion de docs,
    prompt-injection defenses
  - L2 Storage — cifrado at-rest, control de escritura, backups tests
  - L3 Context — prompt template hardening, session isolation, memory
    scoping
  - L4 Planning — goal alignment checks, plan diffing, limits
  - L5 Execution — tool allow-list, sandbox, rate limits, budget
  - L6 Output — schema validation, PII redaction, hallucination checks
  - L7 Inter-agent — auth entre agentes, provenance, replay protection
  - L8 Identity — autenticacion del usuario, autorizacion por rol,
    auditoria
- **[10.5c]** Marcar cada capa con `status: passed|partial|pending|missing`
  en el frontmatter.
- **[10.5d]** Ejecutar `apex_security_gate(scaffold=false)`. Si alguna capa
  NO esta `passed`, el gate devuelve BLOCKED y NO se avanza a fase 11.
- **[10.5e]** Resolver findings: implementar mitigaciones, re-evaluar, hasta
  que el gate devuelva PASSED.
- **[10.5f]** El gate 10.5 NO es una fase: no se registra con `apex_set_phase`
  (el schema solo acepta enteros 0-14). Su cierre queda evidenciado por las 8
  capas en `status: passed` + `apex_security_gate` PASSED. Registra el paso con
  `apex_add_decision(category="security", decision="Gate 10.5 passed", ...)` y
  procede a `apex_set_phase(phase_number=11, status="in_progress")` — que el
  gate de seguridad dejará pasar solo si todas las capas están `passed`.

## Criterio de salida

- 8 archivos L1-L8.md existen y estan en `status: passed`.
- `apex_security_gate()` devuelve `passed=true`.
- README.md del security directory actualizado.

## Regla ABSOLUTA

Si el gate no pasa, NO se puede iniciar fase 11. El skill `flow-guardian`
bloquea la transicion.
