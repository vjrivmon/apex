Por qué /apex no se ciñe

Auditoría adversarial multi-agente del mecanismo de enforcement de /apex, con la lente del rubric writing-great-skills de Pocock. La causa raíz de "Claude Code tiene demasiada libertad" no es de wording: es que la fuente de verdad y el artefacto que corre son ficheros distintos, y que el gate es opt-in por el propio agente al que debe restringir.

Fix

Make the running /apex command point at the maintained repo router so the enforcement tools are in scope (symlink ~/.claude/commands/apex.md to the repo, or a build step that copies it). But per the fail-open nature of phase-gate.py (missing grader verdict => transition allowed, line 190-191), do NOT rely on command prose remembering to call the grader: make the grader/close gate fail-closed in phase-gate.py — when transitioning a phase to 'completed' (or the next phase to in_progress) and NO verdict exists for the phase being closed, block with an instruction to run apex_grader_evaluate first, rather than returning 0. Keep the force=True escape hatch. This arms enforcement independently of which command text is loaded.

C9

force=True es auto-certificacion sin friccion

Medio ×2

Cada gate tiene un escape force=True que el propio agente pasa, con un force_reason de texto libre que nadie valida. El agente se auto-aprueba el bypass.

apex_server.py
Fix

Two-tier fix. Tier 1 (cheap, immediate): reject force when force_reason is empty/whitespace instead of substituting "(sin razón documentada)" and proceeding — return an error TextContent from apex_set_phase and have phase-gate.py return 2 (block) when `args.get("force")` is set but force_reason is blank, rather than `return 0`. Make force_reason actually required-on-force by validating it in code (schema `required` can't express the conditional, so enforce it in the handler). Tier 2 (real out-of-band gate): require an env var like APEX_ALLOW_OVERRIDE set by the human, or a force_reason that must match a human-provided token persisted in context.db, so the model cannot self-issue the override. Without Tier 2 the gate remains advisory-to-the-caller; Tier 1 only raises the cost of a silent bypass.
